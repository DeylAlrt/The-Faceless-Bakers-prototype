# The Faceless Bakers — website prototype

A clickable concept website for The Faceless Bakers, an artisan bakery and specialty coffee spot on Hayat Boulevard, Town Square, Dubai.

Built by Dale Alerta as a pitch prototype: [alerta-portfolio.vercel.app](https://alerta-portfolio.vercel.app)

## What's in it

- Four pages in one file: Home, Menu & order, Rewards, Visit (`#/`, `#/menu`, `#/rewards`, `#/visit`)
- The real cinnamon roll and cheesecake menu with AED prices
- Pickup ordering: bag, coffee options, 15-minute pickup slots in Dubai time, order number screen
- Points rewards with three levels and a join form
- Embedded Google Map and opening hours
- Spring-based motion: page wipes, cursor, shared-element menu detail, draggable cards, smooth scrolling

## Notes

This is a prototype. No orders are sent and nothing is charged. The coffee list, rewards perks and join email are placeholders to confirm with the client. Menu photos are crops from the client's Instagram menu and will be replaced with original photography.

## Run locally

Open `index.html` in a browser. No build step. Deploys to Vercel as a static site.
